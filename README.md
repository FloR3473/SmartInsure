# SmartInsure
SmartInsure est un projet d'analyse de données et d'intelligence artificielle appliqué au secteur de l'assurance automobile.

L'objectif est d'explorer les caractéristiques des clients et de leurs contrats afin d'identifier les facteurs associés à leur Customer Lifetime Value (CLV), puis de développer un modèle de Machine Learning capable d'en prédire la valeur.

Le projet couvre l'ensemble du cycle Data :
- Exploration et nettoyage des données avec Python et Pandas
- Stockage et analyse SQL des données
- Visualisation des tendances et relations entre les variables
- Machine Learning avec comparaison de plusieurs modèles
- Suivi des expériences avec MLflow
- Stockage des prédictions en base de données
- Application interactive développée avec Streamlit

Le projet s'appuie sur un jeu de données de 9 134 clients d'assurance automobile contenant des informations sur les profils clients, les contrats, les véhicules, les primes et les sinistres. 
```https://www.kaggle.com/datasets/ranja7/vehicle-insurance-customer-data```

Problématique : Quels facteurs sont associés à la Customer Lifetime Value d'un client d'assurance automobile et peut-on prédire cette valeur à partir de ses caractéristiques ?
